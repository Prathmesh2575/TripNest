# TripNest – Travel Listing Web Application

## Live Demo
https://tripnest-1-mpqe.onrender.com/

TripNest is a full-stack travel listing platform inspired by Airbnb, where users can explore accommodations, create property listings, and share reviews.

## Tech Stack
- Node.js
- Express.js
- MongoDB
- Mongoose
- EJS
- Bootstrap
- Passport.js
- Cloudinary

## Features
- User registration and authentication
- Create, read, update and delete property listings
- Upload and manage property images
- Review and rating functionality
- Authorization and protected routes
- Responsive user interface

## Installation

1. Clone the repository.
2. Run `npm install`.
3. Configure your `.env` file.
4. Run `nodemon app.js`.
5. Open `http://localhost:8080`.
